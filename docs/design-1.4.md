## Summary

Slice 1.4 was the largest of Phase 1 and the MVP gate that closes it, split dependency-shaped into **1.4a** (Tasks 1.4.1–1.4.8, writable foundation) and **1.4b** (Tasks 1.4.9–1.4.17, orchestrator + self-host gate). **1.4a** shipped the in-tree reviewer assets (3 JSON schemas + 6 per-method × per-reviewer system prompts + the v1 PR-body/decomposition/answer templates) under `assets/`, the `io.forge.app.bootstrap.AssetInstaller` that first-run-installs them into `~/.forge/{schemas,prompts,templates}/`, the `io.forge.app.reviewer` wall-clock boundary (`ReviewerCall` / `ReviewerLimits` / `ReviewerOutcome` / `RealReviewerCall`), and the repopulated `forge-specs` module — `SpecStore`/`FileSpecStore`, `DocSync` (decomposition.md re-render), `ChangeCollector` + `StagingConfig` (Allow/Deny/Ask per §10.1). The Task 1.4.7 `ReviewerRegressionSuite` then **closed C15** (≥19/20 native-schema bar on all six method × connector pairs; v1 config claude=`haiku` / codex=`gpt-5.3-codex`, 3-min cap). **1.4b** shipped the headless `Orchestrator` (the §11 feature loop racing source sets into `Fsm.transition`, with the S2-5 atomic-persist order = manifest → action log → state cache), the `io.forge.app.command` CLI + `CommandRouter` for the full §15 command set, the `forge spec` line-mode REPL, `ForgeConfig` + two-phase boot in `Main`, and the §8 CI-readiness wiring (Task 1.4.10b). The **Task 1.4.16 MVP gate** drove `image-creds-dedup` in `llm4s/szork` from `forge new` to `FeatureDone` (design PR #9 merged → implement → CI fail → fix-up ×2 → green → review approve → merge → Refining → FeatureDone), exercising the full §11 lifecycle live. Final test scope at close: forge-core 377, forge-agents 197, forge-git 141, forge-specs 190, forge-app 329 = **1234 unit tests** (0 failures), plus `forge-it` opt-in suites.

Both halves' exit criteria were **met on 2026-05-31**: the MVP run reached `FeatureDone` against `llm4s/szork`, the `roadmap.md` §2.4 `[~]` flipped to `[x]`, Phase 1 closed, and Phase 2 (Slice 2.0) opened.
